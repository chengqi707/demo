# 贪吃蛇游戏 PRD（产品需求文档）

## 1. 文档信息

| 项目 | 内容 |
| --- | --- |
| 产品名称 | 贪吃蛇（Snake） |
| 文档版本 | v1.0 |
| 文档状态 | 草稿 |
| 目标平台 | Web 浏览器（桌面端优先，兼容移动端） |

## 2. 项目背景与目标

贪吃蛇是经典的休闲小游戏，规则简单、上手门槛低。本项目旨在实现一个可在浏览器中直接运行的贪吃蛇游戏，作为演示项目（demo）验证完整的「需求 → 开发 → 交付」流程。

**目标：**

- 提供完整可玩的贪吃蛇核心玩法
- 代码结构清晰，便于后续扩展（关卡、皮肤、排行榜等）
- 无需安装，打开页面即可游玩

## 3. 目标用户

- 休闲玩家：利用碎片时间进行轻量娱乐
- 学习者：通过本项目了解小游戏的基本实现思路

## 4. 核心玩法

- 玩家控制一条蛇在固定大小的网格场地中移动
- 场地中随机出现食物，蛇吃到食物后身体增长一节，同时得分增加
- 蛇头撞到场地边界或自己的身体时，游戏结束
- 随着得分提升，蛇的移动速度逐渐加快，难度递增

## 5. 功能需求

### 5.1 P0（必须实现）

| 编号 | 功能 | 描述 |
| --- | --- | --- |
| F-01 | 开始 / 重新开始 | 进入页面后可开始游戏；游戏结束后可一键重新开始 |
| F-02 | 方向控制 | 桌面端使用方向键 / WASD 控制蛇的移动方向；禁止 180° 直接反向 |
| F-03 | 移动与生长 | 蛇按固定节奏前进；吃到食物身体 +1 节 |
| F-04 | 食物生成 | 食物随机出现在场地空闲格子，不与蛇身重叠 |
| F-05 | 碰撞判定 | 撞墙或撞到自身时游戏结束，展示结束提示 |
| F-06 | 计分 | 每吃一个食物得 10 分，实时显示当前得分 |

### 5.2 P1（应当实现）

| 编号 | 功能 | 描述 |
| --- | --- | --- |
| F-07 | 最高分记录 | 使用 localStorage 持久化历史最高分并展示 |
| F-08 | 难度递增 | 每获得一定分数提升移动速度（设置上限） |
| F-09 | 暂停 / 继续 | 支持空格键暂停与继续 |
| F-10 | 移动端控制 | 触屏滑动或虚拟方向键控制 |

### 5.3 P2（可选扩展）

| 编号 | 功能 | 描述 |
| --- | --- | --- |
| F-11 | 音效 | 吃到食物、游戏结束时播放提示音，可开关 |
| F-12 | 皮肤 / 主题 | 提供多套配色方案 |
| F-13 | 障碍物模式 | 场地中随机生成障碍物，增加挑战 |

## 6. 非功能需求

- **性能**：游戏循环稳定，帧率流畅（≥ 30 FPS），操作延迟不可感知
- **兼容性**：支持 Chrome / Edge / Firefox / Safari 主流浏览器最新两个大版本
- **体积**：纯前端实现，无后端依赖，资源体积小、加载快
- **可维护性**：游戏逻辑与渲染分离，核心参数（场地大小、初始速度、分值）可配置

## 7. 界面与交互

- **主界面**：游戏场地（约 20×20 网格）、当前得分、最高分
- **开始页 / 遮罩**：游戏名称 + 开始按钮 + 操作说明
- **结束页 / 遮罩**：本局得分、最高分、重新开始按钮
- **视觉风格**：简洁扁平，蛇、食物、背景三者对比清晰

## 8. 验收标准

1. 打开页面即可开始游戏，核心循环（移动 → 吃食 → 生长 → 加速）完整可用
2. 撞墙、撞自身均能正确触发游戏结束并可重新开始
3. 计分准确，最高分在刷新页面后仍然保留
4. 反向操作被正确拦截，不会出现「原地掉头自杀」
5. 在桌面端主流浏览器与移动端浏览器上均可正常运行
